# rosetta-nifi-mcp 0.1.1

发布日期：2026-10-18。补丁版本，工具接口与 0.1.0 相同，无不兼容改动。

## 修复

- **顶层分支通道。** 一个处理器接两个 `http_stage` 组、各组的 rejected / failure / ledger 接到漏斗时，
  `stack` 与 `auto` 布局不再把组件挤成一行、连线交叉；主路径自上而下，旁路进入整齐的竖向通道。
- **`http_stage` 模板。** 连接标签不再压在处理器框上（如 “Enter stage”、“HTTP retry”）。

## 新增

- `canvas.py`：从 NiFi API 计算组件与标签的包围盒，检查重叠和穿过组件的连线。
- `scripts/e2e_layout_test.py`：搭四种分支变体，断言没有重叠框、重叠标签或穿过组件的线。

## 验收

对本地 NiFi 2.11.0 实跑，全部通过：

- `e2e_layout_test.py`
- `e2e_nested_build_test.py`
- `e2e_build_flow_test.py`

## 升级

`git pull && uv sync`，重启 MCP 客户端。
